# 主管訓練課程工具集

## 技術職缺成功輪廓卡(`tech-job-profile-card.html`)

「招募觀念與技巧」課程(達發科技)的配套工具,對應「職務具體化」單元。
主管輸入**職缺名稱**、或貼上 **104 職缺頁的工作內容文字**,即產生一張八欄位的
「技術職缺成功輪廓卡」參考草稿(職務使命、6 個月成果、必備能力、可培養能力、
關鍵工作情境、正向證據、風險證據、候選人價值主張)。

- 內建 12 種 IC 設計公司常見技術職系範本(韌體、數位/類比 IC 設計、DV 驗證、
  軟體、DSP/演算法、RF、測試/PE、FAE、硬體、數位後端、PM)+ 通用範本
- 關鍵字比對引擎:從職缺名稱與職務內容比對最接近的職系,並列出偵測到的技術關鍵字
- 每一格內容可直接點擊編輯,支援列印/存 PDF、下載 Markdown、複製全文
- 貼 104 **網址**時會提示改貼「工作內容文字」(瀏覽器安全限制無法跨站抓取頁面)
- 純前端單一 HTML,無後端、無外部套件;輸入不上傳、不儲存;支援深淺色主題

# SMART 目標檢核網站

「目標設定與績效面談」課程(DDI)的課後練習工具。學員將自己或部屬草擬的績效目標貼上,
網站依 SMART 原則逐項檢核、給分,並提出具體改善建議、改寫句型與績效面談提問參考。

## 功能

- **五構面檢核**:具體 Specific、可衡量 Measurable、可達成 Achievable、相關 Relevant、有時限 Time-bound,各構面 0–100 分並標示「良好/部分符合/待加強」
- **證據標示**:列出在目標中偵測到的行動動詞、指標、數字、期限、方法等關鍵內容
- **具體改善建議**:針對缺漏構面給出可直接套用的改寫提示
- **改寫句型**:自動把偵測到的內容套入完整目標句型(在【期限】前,透過【方法】,將【指標】由【現況】提升至【目標值】,以支持【上位目標】)
- **面談提問建議**:依最弱構面產生一對一面談的教練式提問
- **多條目標**:一行一條,可一次貼多條(例如整份部屬目標)
- **列印/存 PDF**:檢核結果可直接列印帶進面談
- 支援深色/淺色主題、手機版面;所有分析皆在瀏覽器內完成,**內容不上傳、不儲存**

## 技術

單一 `index.html`,純 HTML/CSS/JavaScript,無任何後端、外部套件或 API。
檢核邏輯為針對繁體中文目標語句設計的關鍵字規則引擎(見 `index.html` 內 `RE` 規則表),
可直接修改詞庫以貼合公司慣用指標(良率、稼動率、DPPM…已內建常見製造業指標)。

## 公開部署(GitHub Pages)

1. 將本分支合併到 `main`(或直接以本分支部署)
2. GitHub repo → **Settings → Pages**
3. Source 選 **Deploy from a branch**,Branch 選 `main`、資料夾選 `/ (root)`,按 Save
4. 約一分鐘後網站會發佈在 `https://<帳號>.github.io/<repo 名稱>/`

之後只要把這個網址(或 QR code)放在課程簡報最後一頁,學員即可直接使用。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可,無需安裝任何東西。

仍需主管與部屬在績效面談中對話確認。
